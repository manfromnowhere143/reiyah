# Navigation measurement distribution scope

Document: reiyah.navigation-measurement.distribution, version 0.1.1.
Status: proposed exact public-scope boundary.

Public files may contain original mathematical methods, code, wrapper, controls,
aggregate findings, source metadata, hashes, attribution and reproduction pointers.
Keep numeric source prefixes, archive ranges, decompressed bytes, raw HTTP
headers, manufacturer code, manuals and full source-derived traces private.
No sample, archive member, PDF, decoded navigation table or vendor binary is
placed in public Git by this packet. Source-pointer copies alone are evidence
ineligible; scientific reliance binds private retained bytes.

The official .xz file-format specification 1.2.1 is retained privately for
supported archive structure interpretation. Only limited paraphrase and source
identities are distributed. Public aggregate research findings do not supply
physical calibration, legal compliance or independent scientific acceptance.
