# Distribution boundary, 0.1.0

Only session-authored code, methods, aggregate derived facts, source identities,
cost summaries and verification records are distributed. No code license was
found in the pinned source repository. Its payloads remain private; the separate
sensor archive's CC-BY4 statement is not imported as code permission.

All24captured vendor/data files, paper/project/metadata bodies, complete per-visit
traces, stdout from the original vendor tool and failed stderr remain private.
Public results report case counts, errors, nominal decisions and explicit gaps.
The named missing checkpoint is a fact needed to identify an absent operand;
its coordinate and raw timestamp rows are not distributed.

The experiment uses public recorded positions and independently authored
publisher software without treating them as scientific or release authority.
No sensor archives, image files, reserved images, model inference or private
perception-team records were accessed. No outreach occurred.

Publisher push/readback may verify exact distribution bytes. It is not
independent transport observation, scientific replication or Gate A acceptance.
