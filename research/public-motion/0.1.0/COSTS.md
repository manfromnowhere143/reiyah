# Measured costs and retained boundaries

Document ID: reiyah.public-motion.costs-note. Version 0.1.0.
Lifecycle status: exploratory.

The [machine ledger](costs.json) records completed commands through its named
cutoff. It separates source retrieval, setup, controls, actual calculation,
checking, packaging and the integrity-control harness. The two calculation
commands cost 0.123960875 and 0.123304958 outer-process seconds. Their tasks
differ, so these values are not a latency or economic comparison.

The source captures total 889,855 bytes across five successful public requests.
The raw bodies, PDF text extraction and retained mutation fixtures stay private.
All temporary control roots are under the owned packet and included in its
artifact accounting. No external temporary checkout was created. The fresh
checkout and shared Git objects are accounted separately; the Git metadata
warning is retained without unrelated cleanup. Ceilings remain 8 MiB of source,
128 MiB of new owned artifacts, 600 seconds each for execution/checking and
5 GiB free disk.

Known preparation tool wall reports lacking UTC placement remain separate.
Nested source-request, child-process and control measurements are not added to
their parent durations. The UTC-envelope union is not active engineering time.
Three pre-execution control runs reflect input-binding changes; the final
37 controls/27 scalar cases are the evidence count, not three independent sets.

The public cutoff precedes this accounting write and later consistency checks,
integration and publisher readback. Those costs appear in the private final
closeout, with explicit later cutoffs. Source/selection/freezing failures were
not suppressed: two mistaken local read paths were corrected, web rendering
limits remain, and expected malformed/tampered control rejections are retained.
The actual eight allocated cases and their checking completed without a cap
or failed case.

Useful engineering time, human effort, provider charges, energy, peak process
memory and complete workflow cost are unknown. This phase does not claim a
savings ratio, an investment target or five/ten hours of useful work. The
original mission start and closed ten-hour assignment remain historical; this
new phase does not restart or pad them.
