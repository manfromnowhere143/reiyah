# Witness and verification scope

Version `0.1.0`. This is an outcome-informed development follow-up.

For each selected filtered state, keep the original projected reference
set and the preceding one-edit universal interval. The inherited construction
uses prediction/reference shapes and fixed predecessor constructions, then
enumerates exact one-axis IoU cells at each fixed orthogonal position.
Each rectangle induces a matching neighborhood. Test each distinct
neighborhood against every allowed reference deletion and the no-deletion
choice, including the unchanged/deletion-only worlds. An insertion,
deletion or replacement is one edit under the frozen original contract.

The best constructed lower/upper world improves an inherited endpoint
only when its exact matching-loss delta is strictly smaller/larger. A tie
retains the original proof choice. All new search endpoints remain retained,
including those not selected for a composed case. Existing universal bounds
do not depend on finding a witness; an attained bound proves that endpoint
exact for those operands. Failure to attain a bound does not prove it tight.

Per-image case witnesses sum one allowed component world per image. A global
one-edit case replaces exactly one component of its nominal sum. The usual
strict mean-improvement decision follows the unchanged universal interval.
Only an attained interval crossing zero with a strictly positive upper value
establishes opposing decisions. Other partial timing families remain untouched.

The verifier reconstructs each edit from its operation and reference identity,
checks geometry/cardinality, recomputes matching with the separate certificate
path, checks native payloads, and checks proof-to-world bindings. It derives
the expected state from the old state plus those exact endpoint choices and
rejects changes to any other field. Every case is recomposed by the separate
case checker. Original proof bytes are bound to the completed parent check;
this reuse is explicit and is not an independent reproduction of that check.

There are no new source assumptions or third-party algorithms. The finite
search, exact IoU convention and reference semantics are inherited from
the [original geometric analysis](../../public-predictions/0.1.0/ANALYSIS_PLAN.md).
No experiment is rerun on raw images, no new prediction is generated and no
reserved outcome is accessed.
