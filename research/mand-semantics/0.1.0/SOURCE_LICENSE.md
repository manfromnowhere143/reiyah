# Source attribution and retained-payload boundaries

Document ID: `reiyah.mand-semantics.source-license`. Version: `0.1.0`.
Lifecycle status: `exploratory`. 16 October 2026.

The manD 1.0 dataset by **Khazar Dargahi Nobari and Torsten Bertram**, Harvard
Dataverse release 2.0, 24 January 2024, DOI [10.7910/DVN/SG9TMD](https://doi.org/10.7910/DVN/SG9TMD),
is provided under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The same authors' dataset descriptor, Scientific Data 11, 327, 30 March 2024,
DOI [10.1038/s41597-024-03137-y](https://doi.org/10.1038/s41597-024-03137-y),
also records CC BY 4.0. The derived release inventory, function locations and
source summaries retain that attribution. Changes select source identities,
inspect code structure and distinguish documented meaning from unqualified claims.
Original metadata, code, article and participant payloads are not republished here.

**Khazar Dargahi Nobari**, *Modeling human driver in takeover scenarios: a
neuropsychological model informed by physiological dynamics*, TU Dortmund,
2025, DOI [10.17877/DE290R-25668](https://doi.org/10.17877/DE290R-25668), was
accepted on 24 June 2025 and made available on 28 August 2025. The institution's
publicly served text derivative and metadata are retained privately. The deposited
license grants rights to the repository operator; no redistribution grant to
Reiyah is recorded. This packet publishes attributed interpretations, identities
and locators, without reproducing the text or PDF.

TU Dortmund RST's official manD pages are public read sources. Their original
HTML remains private because no redistribution permission is recorded. Reiyah's
authored scripts and analysis remain under the repository's Apache-2.0 license.
Source licenses and integrity checks convey no scientific or operator acceptance.
