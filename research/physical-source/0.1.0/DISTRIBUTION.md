# Distribution scope, version 0.1.0

Document ID: `reiyah.physical-source.distribution`.

Publish Reiyah-authored review, audit code, request specification, source metadata,
aggregate inventory arithmetic and validation results only. New Reiyah code is
under the repository Apache-2.0 license. Retain paper bodies, extracted text,
third-party source code, licenses and HTTP receipts privately. No trajectory,
mesh, raw sensor or image payload was fetched or enters Git.

The pinned dataset host carries a custom license allowing research and commercial
R&D subject to restrictions. Redistribution has attribution, full-license and
unmodified-form conditions, with further restrictions on personal data. The
GitHub README instead says license on request. Retain both declarations. Do not
infer permission to publish a transformed trajectory extract from either a public
download route or the card's shorter summary. The exact source terms remain in
the private retained license; this is an operational custody choice, not a legal
compliance opinion. Authors: Philipp Berthold, Bianca Forkel and Mirko Maehlisch,
University of the Bundeswehr Munich; dataset license names UniBw LRT8.1 PAD.

The arXiv paper uses its perpetual non-exclusive distribution license. The OxTS
documents and GitHub code have no verified general redistribution grant here.
Metadata pointers in public Git are insufficient evidence without their retained
bytes. Checksums authenticate the retained content, not the authors' calibration.
Publisher push/readback supplies exact distribution assertions from this session,
not independent transport verification, scientific acceptance or replication.
