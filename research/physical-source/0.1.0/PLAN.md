# Physical source qualification, version 0.1.0

Document ID: `reiyah.physical-source.plan`. Status: exploratory.

Qualify one concrete source against the input contract of the existing continuous
clearance calculation. 7V-Scanario was selected after public documentation review;
this is an exposed source investigation, not a preregistered empirical study.
Freeze the review, source identities and audit code before the retained audit.
Do not run an invented physical comparison when the source contract is incomplete.

The allocated work is metadata and methods qualification, one offline custody and
inventory audit, eight rejection controls, two frozen-file mutation controls,
and the current research consistency
entry point. No trajectory, sensor, image or mesh payload is allocated. No new
authored mathematical sweep, old NGSIM window or reserved image is opened. Zero
physical cases is an execution fact, not a zero-error result. Source qualification
and the physical outcome have separate statuses.

The audit verifies hashes, Git blob identities, pinned repository inventories,
archive-size arithmetic, closed review fields and conservative claim scope. It
does not independently validate the authors' calibration, decide source rights,
establish semantic correctness of the review or supply independent replication.
All such judgments remain explicit review statements. There is no A/B arm.

Use the pinned installed Python and owned supervisor. Network is denied before
offline child Python starts. Keep public requests separate, bounded and recorded.
Current increment limits: 128 MiB nonenvironment artifacts including owned
temporaries; 8 MiB captured source bodies including derived text; 5 GiB free disk
floor; 600 cumulative execution seconds and 600 cumulative checking seconds.
Failed attempts count; other supervised commands have 120 seconds each. The new
checkout is accounted separately. These are ceilings, never duration targets.

Retain every failed request, guard refusal and unresolved field. A changed frozen
file requires a new freeze and a retained predecessor. Report nested child CPU
separately from outer wall time; do not add nested time to its parent. Unmeasured
engineering effort, tool/network overhead, memory peaks, energy and charges stay
unknown. Publisher readback is not independent transport verification.

Stop this source's physical experiment if evidence or bounded access is missing.
Specify the smallest useful source-bound extract and its admission conditions.
Daniel need not own private records or repeat general authorization. Follow public
leads within the existing boundaries; contacting maintainers is a separate action.
Keep the historical controller, existing results and 1,433 reserved images closed.
