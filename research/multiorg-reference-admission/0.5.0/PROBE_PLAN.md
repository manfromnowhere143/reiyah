# Complete first-image pair: prospective execution boundary

Version 0.5.0. Written before model execution on 14 October 2026.

Question: can the exact tested corrected Faster observation graph and unchanged
released YOLO candidate produce a completely checked analysis endpoint for the
first predeclared image? The image and prior partial observations are exposed.
This is not a fresh accuracy or work-saving test.

Run the two candidates once, in Faster then YOLO order, over all 156 declared
tiles each. Bind execution/protocol.json, manifest.json and INPUT_ROSTER.json,
the worker, all numerical/reference modules, the separate file checker and its
qualification, the existing runtime audit, sources, and source bytes in a
prospective freeze. No empirical forward pass is authorized before that freeze.
No automatic or hidden retry is allowed. ORT session-creation and run fallback
are disabled; successful numerical settings remain unchanged.

Ceilings: 600 seconds, 3 GiB sampled worker RSS, 312 forward passes, one image,
156 tiles per candidate, 200,000 final raw rows per candidate, 64 MiB per array
file and 128 MiB aggregate arrays. Static output and row caps derive a maximum
66,823,136 bytes with conservative NPY overhead. JSON files separately have
64 MiB limits; the supervisor reads at most 1 MiB for the root result. Keep at
least 4 GiB free disk. RSS is sampled, not a hard instantaneous address-space
bound. Worker networking is denied before Python starts; host observation is
outside that sandbox. No installs, downloads, training or paid services.

Preserve all 33 named Faster outputs and both YOLO outputs before admission.
Bind each actual model input to the independently reconstructed 312-tensor
roster. For every Faster tile check its own observed origin mask, direct removal
of only explicit appended RPN origin, selected identities and final bytes.
Do not manufacture original-graph baselines. Enforce finite and genuine
high-score geometry without clipping or repair. Preserve low-score anomalies.
Use float32 score strictly above 0.5 and the unchanged coordinate mapping,
flooring, stable ordering and whole-image hard NMS after complete coverage.
This contract does not define the complete lower-threshold storage endpoint.

Stop on any binding, schema, origin, selection, geometry, coverage or resource
failure. Retain available raw arrays, per-tile receipts and process refusal.
Do not restart, raise thresholds or budgets, substitute models/images, infer
empty output from missing tiles, or revise a frozen checker to accept outcomes.

After the attempt, the separately authored checker must reconstruct inputs,
verify complete retained arrays and own-origin admissions, and independently
recompute coordinate transforms and global NMS. Its read-only budget is 300
seconds; no model inference. Repeat runtime RECORD audit and every frozen
digest. A process completion alone is insufficient. Neural computation and
physical truth are not independently validated by this arithmetic check.

Only a fully qualified pair permits a separately frozen reference comparison
using the three existing annotation procedures and unchanged native bounds.
The four-image cohort and equal-information complete-work comparison remain
separate dependencies. Gate A remains operator-unaccepted; this research does
not establish production readiness, superiority or operator acceptance.
