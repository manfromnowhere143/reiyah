# Decision: qualify the complete first-image pair

Document ID: `reiyah.multiorg.corrected-pair-decision`. Version: `0.1.0`.
Lifecycle status: `proposed`.

The exposed-tile experiment supports the narrowly specified origin correction.
The next consequential uncertainty is whether the fixed detector pair can
complete the first predeclared whole image under explicit output and reference
contracts. Another exposed-tile variation would not answer that question.

## Alternatives

| Route | Assessment |
| --- | --- |
| Delete zero boxes after the original output cap | Reject as the general correction: origin is ambiguous and a slot may already be lost. |
| Run the ordinary corrected export immediately | Requires a separate empirical parity check; only its observation variant was executed. |
| Use the exact tested observation variant for the first whole image | Recommended bounded route. Retains direct origin evidence at each tile, with explicit memory and I/O costs. |
| Raise thresholds, choose another image or train another model | Reject for this milestone: changes the comparison after observing failure. |
| Stop after the successful tile | Preserves a useful local correction, but leaves the original pair dependency unresolved. |

Use the same frozen first image and the same YOLO source candidate. Name the
corrected Faster observation graph as a new candidate; do not substitute it
silently into the original failed protocol or inherit the released model's
performance claims. Keep image reconstruction, tile order, preprocessing,
analysis score > 0.5, whole-image NMS, matching and reference semantics fixed.

Keep all 33 declared outputs and the same fetch roster and CPU session settings.
Before execution, qualify a tile adapter that checks every origin mask and
direct-removal result, retains raw rows/exclusions, and enforces genuine
high-score geometry. Validate that extra observation outputs do not accidentally
change the adapter's dets/labels parsing. Record complete expected tile coverage,
both model identities, all opportunity counts and every refusal. Run only the
exact tested graph; a future untapped export needs its own qualification.

For new tiles, check the corrected variant's own raw-head, origin and selection
contract directly. Do not manufacture an original-model baseline from corrected
arrays. Original-versus-corrected byte preservation remains demonstrated only on
the exposed tile where both graphs were actually observed.

The source lineage and selected-population checks must cover the complete image,
including tiles with no genuine proposals and tiles where the appended origin
does not survive the RPN cap. The single-tile result is not a universal guarantee.
Do not silently discard unrecognized rows or turn an incomplete image into an
empty output. Final zero-score padding remains structural metadata.

## Falsifying experiment and resources

Prepare one new attempt with the prior CPU-first ceiling of 600 seconds and
3 GiB sampled RSS, subject to a prospective array/disk budget from the known
tile roster. Existing bytes and environments suffice; no download, training or
paid service is needed. Freeze adapter code, separate checker, exact variant,
image, tile roster and budgets before any new empirical forward pass.

Stop on the first unexplained origin, selected-identity mismatch, nonfinite
output, genuine final high-score invalid geometry, missing tile or resource
overrun. Preserve partial outputs and the refusal. No automatic retry or tuning.
Success requires every tile of both candidates and independently checked
whole-image postprocessing, not merely a process exit code.

Only then admit the separately qualified reference-matching step. The native
source procedure is a useful comparator but must share explicit semantics;
do not equate fixed recorded annotation procedures with physical truth or a
qualified future reviewer. The four-image primary endpoint and a prospective
complete-work comparison remain separate dependencies. Reserve the untouched
opportunities specified in earlier protocols.

The product test remains the same justified decision with less complete work
than a competent analyst with the same evidence and obligations. Include this
investigation, correction, checking and integration in work accounting. Passing
this next milestone would establish a usable paired input, not superiority.
