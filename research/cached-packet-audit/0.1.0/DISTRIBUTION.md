# Distribution scope

Version `0.1.0`, 18 September 2026.

This folder distributes authored audit code, synthetic controls and factual
aggregate observations. EdgeFirst is the source of the three inspected public
prediction exports and associated publisher metadata. COCO is the source of
the membership/dimension/category index. Apache Thrift and Apache Parquet are
the sources of the retained file-format specifications. Links, versions and
source custody identities are in [SOURCES.md](SOURCES.md) and
[sources.json](sources.json). No publisher endorsement is implied.

Original predictions, derived Parquet views, serialized source schemas,
image-level joins, full timing vectors, task responses, platform/host records,
weights, source documentation and dependency binaries remain private. This
folder does not assert permission to redistribute those payloads. Source
accessibility and a passing content audit are not redistribution grants.

The authored code and synthetic fixtures use the repository's Apache-2.0
license. No third-party source code is copied into this implementation. This
record does not change the separate nuScenes conditions on earlier derived
development-comparison reports or convert them to Apache-2.0.
