Document: reiyah.measurement-resolution.plan, version 0.1.0.
Status: exploratory authored development. Date: 21 September 2026.

The continuing mission remains active across this checkpoint. The closed nominal
ViF-GTAD result is preserved. Its physical uncertainty contract remains missing;
this study does not promote that encounter to physical evidence or rerun it.
The independent useful work here addresses the precise universal-measurement
limitation identified in the operator's supplied review.

Freeze these operands and implementations before executing the nine allocated
authored acquisition experiments. Under the inherited scalar Lipschitz/common
clock contract, determine the complete set of possible measurement responses
and the verdict after each. Then obtain the prescribed oracle response and
recompute the entire updated uncertainty family. A response separating two
selected witnesses is not accepted as proof of universal resolution.

The policy is a fixed declared query order, with early stopping only after a
complete decision, inconsistent premises or an unavailable/unregistered channel.
It is not claimed optimal. Both arms receive identical query opportunities and
oracle values. Query contents, outcomes and controls are authored with known
intent, so this is neither blinded nor held-out evidence. Oracle interpolation
returns numbers from a trace and reporting offset, never a stored verdict.
File preparation and all computation count even when fewer queries are revealed.

## Allocation

| Experiment | Purpose |
| --- | --- |
| Noiseless point at equality | Verify complete resolution and inclusive support boundary |
| Noisy point | Preserve an unresolved feasible response band |
| Pair query followed by complete support | Test the proposed midpoint, then continue through the fixed quarter-time queries |
| Pair query with observed violation | Stop after recomputation establishes contradiction |
| Common clock still ambiguous | Retain shared offset after a repeated recording-time measurement; acquire earlier/later values |
| Inconsistent report | Retain an explicitly injected violation of the reporting-error contract |
| Unavailable query | Refuse acquisition and preserve uncertainty |
| Unregistered query | Refuse clock coercion and preserve uncertainty |
| Initially supported | Perform zero unnecessary acquisitions |

Nine authored piecewise-affine oracle traces supply 15 planned query opportunities.
Nonfault traces must satisfy the initial observation and global rate contract
(constant extension outside the trace supplies a global mathematical witness,
but oracle access outside the listed trace is forbidden). Exactly one disclosed
reporting-fault fixture violates its declared channel error. No model, vehicle,
sensor, image or human measurement is run. Physical cases remain zero.

The producer derives exact support/contradiction thresholds from bad-time and
safe-window sets. The conventional arm projects strict/non-strict two-variable
polyhedra over every time piece. Both classify an infinite response domain with
finite exact operations. They share strict parsing and custody, and have the
same author, but independent arithmetic and protocol/reply reconstruction.
The prior envelope producer and LP witness checker are copied byte-for-byte;
lineage.json binds them. No previous experiment is counted as a new replay.

Before the allocated run, execute the 25 named directed controls in controls.py.
They cover interior uncertainty, equality, noise, shared clocks, zero rate,
outside-horizon queries, strict LP faces, singleton domains, invalid inputs,
channel availability, reuse/extrapolation and byte/freeze tampering. After the
actual run and full separate verification, execute ten declared result mutations.
Do not replace a failed outcome or weaken a rejection. A frozen code change
requires a retained correction and successor binding before new reliance.
