# Qualified retained-score sources

Version `0.1.0`, 18 September 2026. No new source is downloaded.

The two complete local packets and configurations were qualified in
[public-predictions](../../public-predictions/0.1.0/SOURCES.md). Both use all
64 frozen, previously exposed CAM_FRONT images, with untouched numeric scores
strictly above 0.25. YOLO11n retains 487 all-class detections and 297 eligible
car operands; YOLO26n retains 353 and 218. Publisher-empty images remain two
and four respectively. All missing/failed distinctions and image byte/dimension
joins are checked before this study's scoring freeze.

The score-qualification record rechecks each source against the original
admission byte bindings and reconstructs every floor operand. It reads no
reference outcomes or source image pixels and computes no new threshold-dependent
outcomes. The new study retains it in the 343-binding freeze. Source metadata,
weights, image tokens and individual score/geometry joins remain private.
Public threshold boundaries are derived scalar policy events, with no source
detection or raw image association.

YOLO11n uses the frozen class-aware NMS export; YOLO26n uses its frozen end-to-end
head. This study filters their already exported rows. It does not rerun either
postprocessor, import a common NMS convention, regenerate detections or assert
completeness below the retained floor. Equal numeric scores are not assumed
to mean equal correctness probabilities.

Original-reference worlds come from the verified
[full-answer analysis](../../public-predictions/0.1.0/ANALYSIS_PLAN.md).
Camera-time world banks come from the completed
[witness refinement](../../reference-witness/0.1.0/README.md), parent commit
`8e05d6d1c9eb7f5e2fcb3fc4662754d271b70346`. Its results digest is
`2f6f9839551ee735cfadd6275748f1cbff62a36532d4bf43179de709343eefc7`.
The new freeze exact-binds the original reference records, all inherited
per-image world records, preceding results/verification, runtime binary,
source code and controls. Source projection checks are inherited by those
exact bytes; no new claim of independent source replication follows.

All 1,433 outcome-reserved images stay closed. The complete private nominal
threshold-pair matrix is bound in the public summary and reconstructible from
the two published curves. Source conditions remain in [DISTRIBUTION.md](DISTRIBUTION.md).
