# One-capture opening and selection exercise

Procedure ID: `reiyah.perception-viewer.opening`; version `0.1.0`; status `prepared_unobserved`.

This exercises the viewer, not object discovery or reference judgment. Use the coordinator's
exact prepared file and record your actual prior exposure. Do not mark any discovery capture
inspected merely because this file was prepared or checked by code. For actual discovery,
roles, separate source delivery and the [existing staged procedure](../../perception-rehearsal/0.1.0/DISCOVERY_REVIEWER.md)
must first be established. This one file does not replace the full observation package.

1. Record the start time and your Blender experience. Preserve any currently open work. In
   installed Blender 5.1.2 use **File → Open**, choose the coordinator's prepared `.blend`,
   and keep **Load UI** enabled. The prepared file contains no embedded scripts. Open it
   without enabling automatic Python execution. Record whether opening succeeds.
2. The 3D Viewport should show the capture in **Edit Mode**, with **Vertex** selection active
   and no points selected. If it opens in Object Mode, put the pointer over the viewport and
   press Tab; choose the vertex-mode button. Use **View → Frame All** if needed. Record what
   is actually displayed; an empty or unreadable view is a failed/limited observation.
3. Zoom using the wheel or trackpad; use Blender's viewport navigation gizmo to change view.
   Select one visible point with the primary mouse button. A selected point should change
   highlight. The prepared X-Ray setting permits selection through depth; a screen location
   may contain overlapping points. Do not claim a unique physical object from a highlighted
   dot. For several points use the normal box selector, and report that as a region selection.
4. Use **File → Save As** and save to the coordinator's fresh return path. Preserve the
   prepared file. Saving the selected Edit Mode state is enough; no scripts or console
   commands are required. Record the end time, any navigation difficulty and any unintended
   edit. Do not repair geometry to make a later identity check pass.
5. Return the saved scene and the actual observation/time note. The coordinator checks the
   saved scene against the separately held binding and extracts original indices. A rejected
   file is a useful failure to diagnose; an accepted file establishes byte correspondence,
   not human competence, independence, observation completeness or physical truth.

Selection modes and the effect of X-Ray follow Blender's
[5.1 selection manual](https://docs.blender.org/manual/en/5.1/modeling/meshes/selecting/introduction.html)
(page last updated 3 June 2026, retained 12 September). Dense/overlapping point selection is a
known limitation. The precise local screen, controls and time cost still require observation.
The programmatic checks supply no evidence that a participant completed these steps.
