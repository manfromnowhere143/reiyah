## Accepted within the declared scope

For nonnegative integer counts and a positive denominator, the conventional identity remains
`c(m)-1 = (w*(u+m)-x*y)/((u+x+m)*(u+y+m))`. The new classifier distinguishes negative, zero,
positive and unresolved possibilities. Its declared policy rejects the whole domain when the
denominator is zero at `m=0`; this is not a claim that the ratio is undefined at every later `m`.
The numerator is affine in `m`, so its initial value and nonnegative slope give the all-`m`
argument. Finite checks exercise the implementation; they are not that general proof.

An Engine consumer checks **2,401 small tables**, using counts 0 through 6 and unseen counts
0 through 38. All classifications agree with the direct population-ratio oracle and the declared
invalid-domain policy, including integer threshold crossings. This includes 90,090 defined
ratio evaluations on the 2,310 accepted-domain tables; 91 tables are refused at `m=0` even
though later ratios can be defined. Twenty invalid-count controls are rejected.
The direct oracle does not call Fable's coefficient, numerator or
threshold helpers; Python's standard-library parsing and exact fractions remain shared trust.

Fable explicitly withdraws automatic identification from a third channel and the use of an
annotation count as an unseen-population bound. Default `read_submission` now rejects a
substituted file carrying an allowed name because its expected digest differs. This narrow probe
does not establish a complete runtime read boundary: hashing and parsing reopen the path, and a
test-only `verify=False` option remains. That option was refused on this runtime's temporary
path, where path normalization differs. It is not needed to verify the default rejection.

The consumer also recomputes all **18 retained aggregate thresholds**. It does not rebuild
the full raw association grid, replay Fable's reported 581 tests, or validate physical objects.
The captured consumer command took 0.157 seconds with 20,332,544 bytes of macOS child peak RSS.
This is command cost, not a comparison of algorithms or human effort.
