# What the Engine can establish today

Document ID: `reiyah.engine-credibility-review.2026-09-11`

Version: `0.1.0`

Lifecycle status: `exploratory`

Question: does the present Engine support a useful detector-integration decision, and can a
reader reproduce and challenge its reasoning? The implementation supports checked, conditional
comparisons. Its real two-anchor comparison remains **[-8,8]**, with no physical reference
judgments supplied. It has not demonstrated a changed engineering decision, superiority over
equally informed conventional analysis, or state-of-the-art performance.

This bounded internal audit starts from main `2330788c1057e5fdc94be4c15907b70e8e80ee30`.
It inspects the README and all six Mermaid diagrams, their current numerical evidence, the
paired-loss core/checker, and relevant primary literature. It is not a semantic audit of every
historical validator, independent peer review or a new Gate A release. The separate research
lane is not incorporated by this review. Gate A remains operator-unaccepted.

## Mathematical checks and limits

The [public reference calculation](../research/perception-decision-review/0.1.0/README.md)
reproduces four constructed cases without importing Reiyah. An unreachable disputed object
cancels from paired loss; a disputed object near the base changes the matching gain. Sixteen
confirmed candidate objects can leave [-8,8] unresolved. Joint constraints across anchors can
give [0,0] where independent anchor extrema give [-1,1]. These are conventional paired-analysis
and matching facts, not an empirical discovery or a guaranteed physical review budget.

Two fresh invocations reproduce the same 1,312 output bytes. The example also exercises all
512 small labelled graphs and six penalty pairs. Separately structured checks against the existing
Engine/checker confirm the matching trap, sixteen-object extension and shared-target cancellation.
The [verification record](../research/perception-decision-review/0.1.0/verification.json) binds
the example and retained outputs. These are internal computational checks, not independent
scientific review or a statistical sample.

The checker does not invoke the producer's matcher. Both trust the common parser, schema and
rational conventions; neither establishes the physical correctness or completeness of an input
graph. Exact finite enumeration is bounded by 4,096 **raw Boolean assignments** and 2,000,000
estimated work units. The bound counts the full domain before using constraints to discard
worlds. A reproduced 13-variable model with all variables fixed has only one feasible world,
yet returns the sound resource-limited count enclosure. This is a concrete efficiency limit.
If no feasible assignment can be checked, model consistency and the decision remain unevaluated.

A future constraint-aware or decomposed solver could improve that case. It would need the same
global semantics, a checkable coverage argument, adversarial comparison with exhaustive cases,
and measured costs. This review does not replace the solver speculatively. Its first practical
bottleneck remains usable physical-reference evidence, not compute capacity.

## Relevant primary work, reviewed 11 September 2026

This is a targeted comparison of relevant methods, not an exhaustive frontier ranking. Exact

remain private. No method was rerun or benchmarked here, and none of these papers validates Reiyah.

| Method and source | What it provides | Consequence for this Engine |
|---|---|---|
| [TIDE, ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123480562.pdf) | Detection error decomposition using hypothetical corrections and changes in AP; it also discusses annotation problems | Error diagnosis and annotation auditing have established comparators. Reporting either is insufficient for a novelty claim |
| [Noise-Aware Evaluation of Object Detectors, WACV 2025](https://openaccess.thecvf.com/content/WACV2025/papers/Llerena_Noise-Aware_Evaluation_of_Object_Detectors_WACV_2025_paper.pdf) | Triangle-inequality bounds on box similarity; estimated annotation noise is used to construct adjusted IoUs and AP evaluations | Evaluation under uncertain labels and interval reporting are prior work. Compare declared noise models and losses, rather than treating any interval as a differentiated capability |
| [Calibrating Probabilistic Object Detectors with Annotator Disagreement, arXiv:2605.24722v1, 23 May 2026](https://arxiv.org/abs/2605.24722v1) | Aligns predicted class/box uncertainty with the distribution of multiple annotators' labels | Annotator agreement is a distinct target from physical coverage. Keep individual records and justify the aggregation and missingness model before adopting calibration |

In the WACV paper, section 3 focuses on bounding-box localization noise. Its fitted model uses
paired original/corrected boxes, filtering and an iid corner-noise assumption; section 3.4 uses
expected noise in the adjusted metrics. Our inference: those expected adjustments are not a
replacement for an enclosure over every admitted shared reference interpretation, nor proof of
coverage for missing physical objects. A common-loss comparison would require a justified adapter.

The 2026 manuscript's section 3.2 groups annotations and treats an annotator's absent cluster
entry as background. Our workflow requires explicit inspection/availability before interpreting
absence as a negative. That premise must be checked rather than imported. The inspected arXiv
version names Neurocomputing in its header; a journal publication record was not established by
this review. Its reported calibration results are not independently reproduced here.

## The next result worth pursuing

Use the existing development review kit with competent independent discovery reviewers, a
conventional analyst and adjudication. Preserve independent discoveries before assistance, give
both methods identical admitted interpretations, and record preparation, review, computation,
integration and repair effort. The conventional analyst may use the same mathematics.

The useful question is whether the Engine finds a consequential unsupported conclusion or
supports the same decision with less total work. Equal conventional performance is a valid
negative result for differentiation. A correct unresolved result may still help if it identifies
an observation worth acquiring, but that usefulness must be observed in practice.

The proposed 60-scene study remains unselected and unrun. Its protocol is unchanged; a small
synthetic case or development rehearsal does not replace it. Current-generation detectors,
statistical generalization and other domains require separately justified experiments. This
checkpoint makes the existing reasoning easier to inspect; a public breakthrough claim must
wait for evidence beyond that improvement.
