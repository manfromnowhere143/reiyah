## The conditional algebra

Let `w` be paired captures, `x,y` single-channel captures, `u` objects in an observed common
universe seen by neither member of the pair, and `m` additional unseen objects. This is a
conditional object-table model, not a proof that greedy box associations are physical objects.
For nonnegative integer counts and positive denominator:

```text
c(m) = (u+m)(w+x+y+u+m) / ((u+x+m)(u+y+m))
c(m)-1 = (w(u+m)-xy) / ((u+x+m)(u+y+m)).
```

With `u=0`, `w>0` and `x,y>0`, both signs occur as the unbounded nonnegative integer `m` varies.
The first strictly positive integer is `floor(xy/w)+1`; equality is possible only if the
threshold is an integer in the valid domain. The nine retained rows meet those positive-count
premises. Their threshold arithmetic agrees, and 7,710 tiny valid-denominator controls confirm
the general numerator identity.

A third-reported count is insufficient by itself. At `(w,x,y,u)=(1,2,2,1)`, `c(0)=2/3` and
`c(4)=50/49`. Thus `u>0` can coexist with an unresolved sign. Under this model, `wu>xy` is a
sufficient all-`m` positive-sign condition; an additional detector neither guarantees that
inequality nor establishes the object's reality or the association's validity.

The blanket two-channel statement also needs boundaries. At `(w,x,y,u)=(0,1,1,0)`,
`c(m)=1-1/(m+1)^2<1` for every finite nonnegative integer `m`. The exported routine reports
`undefined` because `xy/w` is undefined; that does not make this coefficient or its sign
undefined. Zero marginal denominators, empty populations, equality and limits require separate
states. A scalar threshold alone is not a complete identified-set contract.

Comparing `xy/w` with 134,565 annotated records gives a numerical scale, not an upper bound on
unseen physical objects or evidence that a result is implausible. An annotation count, unmatched
predictions, duplicate records and physical opportunities are different units. The claim needs
a defensible population/error model before a physical interpretation is warranted.

## Constructor and association obligations

The exported source reader guards basenames but does not verify expected source bytes itself.
A substituted small file named `megvii_val.json` is accepted by that function in the retained
probe. This does not prove the historical run used wrong bytes; it identifies a premise not
enforced by the exported constructor. Scanning `.json` literals in source is not an execution
trace or a complete file-access boundary. A reproducible consumer needs separately selected
digests, actual opened paths and an honest denied-access control.

The declared greedy rule is sensitive to source row order. In one class and one frame, place
left detections at `0,0.9` and right detections at `0.5,-0.8` on a common horizontal axis, with
radius 1. The selected implementation pairs one object in that left order and two after
reversing it. This is a property of the chosen heuristic, not automatically a bug. Preserve the
order and original indices, compare against a maximum-cardinality baseline when relevant, and
do not call the observed variation solely physical association uncertainty. Missing output,
valid empty output, invalid values and absent frames must remain distinct.

Fable owns those corrections and the next scientific choice. Engine supplies a separate

input directories, the inventory identifies the same two original submissions; matched caches,

This is a scoped inventory, not a global claim that no other input exists. The lack of a third
source need not block a useful association-sensitivity or additive-loss experiment.

The relevant primary-research boundary remains unchanged: reference-free reliability work
predates Reiyah, and fixed-instance classifier results do not transfer automatically to uncertain
object associations. The earlier private review retains Jaffe, Nadler and Kluger (AISTATS 2015)

exactness, baseline parity and internal checks establish no physical truth or state-of-the-art claim.
