# Reiyah

Reiyah is the architecture-stage home of **HARBOR**, the proposed research program for
Human-Automation Readiness, Belief & Operational Risk.

The repository is currently limited to Gate A: an evidence and benchmark architecture for
object-level driver-vehicle belief, readiness, recoverability, joint silent misses, causal
policy effects, explicit unknowns, transfer, and worst-group validation. It is not a
driver-monitoring classifier, product runtime, control system, or claim of scientific,
safety, benchmark, or standards validity.

## Current authorization

Allowed: reviewable specifications, manifests, retained public evidence, strict schemas,
deterministic fixtures, offline validators, and architecture diagrams.

Not allowed: product behavior, model training or inference, deployment, physical-control
integration, private-data ingestion, publication machinery, or operational claims.

## Start here

1. Read [`AGENTS.md`](AGENTS.md) for repository authority and invariants.
2. Read [`docs/SESSION_HANDOFF.md`](docs/SESSION_HANDOFF.md) for current state.
3. Read [`docs/PRE_IMPLEMENTATION_GATE.md`](docs/PRE_IMPLEMENTATION_GATE.md) for the Gate A
   decision boundary.
4. Run the offline validation described in [`docs/VALIDATION.md`](docs/VALIDATION.md).

Passing validation establishes only that the architecture packet is internally consistent.
It does not create operator acceptance. No acceptance record is present unless an authorized
operator separately creates one under the procedure in [`gate/README.md`](gate/README.md).
